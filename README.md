# Student Marks Calculator

A simple beginner-friendly student project built with HTML, CSS, and JavaScript. It calculates a student's total marks, percentage, grade, and pass/fail status for five subjects.

## Features

- Enter student name and roll number
- Enter marks for five subjects
- Validate marks from 0 to 100
- Calculate total marks out of 500
- Calculate percentage
- Display grade and pass/fail status
- Responsive layout for mobile and desktop
- Clear the form and start again

## Grade Rules

- A+: 90% and above
- A: 80%–89.99%
- B: 70%–79.99%
- C: 60%–69.99%
- D: 50%–59.99%
- E: Below 50% if passed
- F: Fail if any subject mark is below 35

A student must score at least 35 marks in every subject to pass. These grade rules are sample rules for this project and can be changed to match your institution.

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter the student details and marks.
4. Click **Calculate Marks**.

No extra software or packages are required.

## Project Files

- `index.html` — page structure and form
- `style.css` — design and responsive layout
- `script.js` — calculation and validation logic
